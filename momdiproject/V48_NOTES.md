# Prospecting Beast v48 — Premium Experience

v48 is a visual/UX polish release built on v47 Multi-Path Discovery. Core enrichment, prospecting, LinkedIn Direct, adaptive partitioning, token routing, safety guards, and provider workflows are unchanged.

## Changes

- Credits drawer is now provider-neutral: visible labels use Primary token / Secondary token / Token balance rather than provider/API key names.
- Premium glass/depth visual system across Enriching and Prospecting.
- Pointer-reactive ambient lighting with reduced-motion support.
- Smoother workspace transitions, result reveals, progress shimmer, card hover depth, button micro-interactions, and modal/toast animation.
- Enrichment processing has a scan animation and cleaner token-oriented status language.
- Prospecting results now include compact initials avatars, staggered row entrance, clearer profile action, and richer hover hierarchy.
- Role selector, search controls, progress rail, summary metrics, and token drawer received refined focus/hover states.

No discovery or enrichment backend behavior was changed in this release.
